# Three Roots Animal Nutrition — GitHub Pages Test Package

This is the complete bilingual sales presentation for Three Roots Animal Nutrition. It includes the main landing page, interactive product exploration, a presentation-only shopping cart and checkout, Texas delivery information, contact details, champion-breeder photographs, and the manufacturing-plant image.

## Upload

1. Extract the ZIP before uploading.
2. Upload every extracted item to the root of the GitHub repository.
3. Confirm that `index.html`, `shop.html`, `store.css`, `store.js`, and the `assets` folder appear at the same repository level.
4. Commit the files to the `main` branch.
5. Open **Settings > Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select `main`, `/(root)`, and **Save**.

GitHub will provide the website address after deployment finishes. Enabling GitHub Pages makes that address publicly accessible.

## Test after deployment

- Open the homepage and confirm the logo, feed products, plant, booth, customers, and business-card photographs load.
- Switch between English and Spanish.
- Open `shop.html`, add products to the sample cart, and continue to `checkout.html`.
- Check the website on a phone and desktop computer.
- If GitHub shows an earlier version, perform a hard refresh with `Ctrl + F5`.

## Review status

The pages retain `noindex,nofollow` while the owner reviews the presentation. Store prices are samples. The card and ACH checkout is not connected to Stripe, does not request payment credentials, and cannot process payments. A secure server-side Stripe integration is required before accepting real orders.
